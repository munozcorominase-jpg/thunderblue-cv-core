# ThunderBlue CV Core

A fully self-contained professional CV generator built in a single HTML file.

## Features

* Live CV editor
* Multiple dynamic templates
* Webcam integration
* PDF export
* LocalStorage autosave
* Responsive design
* Offline-first architecture
* Zero dependencies
* Zero frameworks
* Single-file application

## Philosophy

This project explores how far a modern frontend application can go using only native browser technologies.

No React.
No Vue.
No npm.
No build tools.

Just HTML, CSS and JavaScript.

## Why?

Modern web apps often depend on massive ecosystems and build pipelines.

This project takes the opposite approach:
minimalism, portability and self-contained architecture.

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Browser APIs

## Run

Just open:

```bash
index.html
```
